# SaberFlow — Plataforma de Estudos e Revisões

Plataforma web full-stack desenvolvida para otimizar o aprendizado e a memorização por meio da técnica de **revisão espaçada** (com ciclos automáticos de 24h, 7d, 15d e 30d) e gestão de flashcards.

## 🚀 Tecnologias Utilizadas

### Back-end
* **Python** (versão 3.10+)
* **FastAPI** (Framework web de alta performance)
* **SQLAlchemy** (ORM para mapeamento objeto-relacional)
* **Pydantic** (Validação de dados)
* **Passlib / Bcrypt** (Criptografia e segurança de senhas)

### Front-end
* **HTML5, CSS3 e JavaScript Moderno (ES6+)**
* **Bootstrap 5 & Font Awesome** (Componentes visuais e ícones)
